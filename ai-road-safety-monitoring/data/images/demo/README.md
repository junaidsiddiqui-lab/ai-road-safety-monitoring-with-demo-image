# Demo image notice

`synthetic_urban_traffic_motorcycles.png` is an AI-generated, realistic-looking illustrative scene included to test image loading, preprocessing, edge detection, and feature extraction in the project.

It is **not a real photograph**, is **not a labeled training image**, and must not be reported as real-world collected evidence or used to claim model accuracy. For real-world evaluation or model training, use appropriately licensed, genuinely captured or openly licensed images and record the source and license. A public motorcycle/helmet dataset option is listed in `../../../../LICENSE_AND_DATA_SOURCES.md`.
